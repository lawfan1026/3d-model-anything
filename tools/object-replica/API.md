# Local object replica API

`python tools/object-replica/replica.py serve` binds **127.0.0.1:5190**, serves `apps/object-review/dist`, and stores private captures in ignored `data/object-captures/`. Set `COLMAP_PATH` to the portable `COLMAP.bat` or its parent directory. CLI commands: `doctor`, `import ZIP`, `reconstruct PROJECT_ID`, `validate PROJECT_ID`, `resume PROJECT_ID --poisson-trim 5`, `evidence PROJECT_ID`, `serve`. Global `--store` and `--colmap` options precede the command.

Every normal reconstruction ends with holdout localization against frozen sparse geometry, using a copied validation database and images. Held-out photos never enter dense geometry or texture generation. `validate` applies this separate stage to an existing succeeded run. `run.validation` records localized IDs, source point/camera invariants and production artifact hashes before/after. Successfully localized holdout cameras join `run.cameras` with `role:"holdout"`; `registeredCount` remains the reconstruction-input count. Failed localization is a warning, not a claimed comparison. `resume` creates a **new** derivative run from a preserved fused cloud and records provenance; it skips expensive feature/SfM/stereo/fusion stages without overwriting the previous run. Default Poisson density trim is 5, recorded explicitly; this numerical threshold is not physical resolution.

- `GET /api/status` → `{colmap:{available,path,version,commands,errors}, python, store, privacy}`.
- `GET /api/projects` → `[{id,name,createdAt,photoCount,reconstructCount,holdoutCount,latestRun}]`.
- `POST /api/import`, `Content-Type: application/zip`, raw ZIP body → full project (201), or `{error}`.
- `GET /api/projects/{id}` → `{id,name,manifest,photos,physicalMeasurements,measurements,runs,latestRun,scale,warnings}`. Photos are original observations plus `url` and `registeredCamera` when available.
- `POST /api/projects/{id}/reconstruct`, JSON `{epoch?,maxImageSize?:integer}` → new run (202). Each run has a unique directory. Mixed epochs require selecting one. Holdout photos are excluded.
- `GET /api/projects/{id}/status` → latest run or `{status:"idle"}`.
- `GET /api/projects/{id}/files/{relativepath}` → source or derived asset. Paths are relative to project root (e.g. `original/photos/000001.jpg`, `runs/<runId>/dense/textured/mesh.ply`).
- `POST /api/projects/{id}/measurements`, JSON `{label,valueMm,role:"scale"|"check",a:[x,y,z],b:[x,y,z],runId?}` → full project. Points are in the **original unscaled mesh coordinates**, never viewer display coordinates. Labels and two endpoints refer to the same physical distance. Requires a succeeded run. Imported physical observations remain unchanged.
- `GET /api/projects/{id}/evidence` → `{path,reportUrl,promptUrl,contactSheetUrl,hashesUrl}`. Creates a new local evidence packet. No upload.

Run shape: `{id,status:"queued"|"running"|"succeeded"|"failed",stage,createdAt,updatedAt,epoch,photoCount,holdoutCount,registeredCount,unregisteredPhotoIds,engine,commands,warnings,error?,model?,cameras?,scale}`. `model` is `{meshUrl,textureUrl,meshPath,texturePath}`. Flat compatibility aliases are `meshUrl`, `textureUrl`, `registeredImages` (count) and `scaleFactor` (meters per raw model unit). `cameras` is an array of `{photoId,file,width,height,intrinsics:{fx,fy,cx,cy},cameraToWorld:[16 column-major values],photoUrl,imageKind:"undistorted"}`. Recovered camera axes are OpenGL: +X right, +Y up, −Z forward. These transforms and the unscaled mesh share the same numerical world. **Matched-camera review must use camera.photoUrl**, the corresponding undistorted derivative. Raw originals retain their original lens distortion. `originalCameras` additionally preserves the recovered raw-image model and distortion parameters.

`scale` is `{status:"unscaled"|"phone-estimate"|"measured",metersPerUnit:null|number,measurementId?:string,rmsResidualMm?:number}`. A ruler `scale` measurement always wins; otherwise a `good` `run.phoneScale` (similarity fit of ARCore to recovered camera centres per tracking epoch) gives `phone-estimate`. The `epoch` reconstruction option selects an object pass (`objectPass`, falling back to `epoch` for captures from Android 0.1.x). It is a unit conversion, not a precision certificate. Annotation records include `{id,runId,label,valueMm,role,a,b,meshDistance,predictedMm?,residualMm?,createdAt}`. Check residuals are computed with the latest scale annotation for that run. No scale is inferred from a typed number without selected endpoints. A viewer may scale the mesh for display, but must map picked points back to raw coordinates.

Error responses are JSON `{error:string}` with 400/404/409/413/500. Requests reject non-local Host/Origin headers. File APIs do not expose arbitrary laptop paths. The server does not allow cross-origin writes.
